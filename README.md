# Final Project

## Emotion Detection Application

This Final Project is an Emotion Detection application using Watson NLP.

The application analyzes text and identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The application also identifies the dominant emotion.

## Technologies Used

- Python
- Flask
- Watson NLP
- HTML
- CSS
- JavaScript
- Bootstrap

## Features

- Emotion detection
- Dominant emotion detection
- Web-based interface
- Error handling
- Unit testing
- Static code analysis
